# Data

This project uses two primary data sources:

- **Trade Map** – historical country-level import data for HS 850760 (lithium-ion accumulators).
- **Global Trade Alert (GTA)** – trade-policy interventions affecting the selected product and markets.

## Data Availability

The original raw datasets are not included in this repository due to potential licensing, access, and redistribution restrictions associated with the source platforms.

The analysis notebook contains the full data-processing workflow, including:

- data cleaning
- country-name harmonisation
- transformation to country-year format
- feature engineering
- trade and policy data integration
- model-ready dataset preparation

Only derived outputs or sample data may be added to this repository where redistribution is permitted.
