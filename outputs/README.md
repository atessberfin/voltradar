# Outputs

This folder is reserved for generated VoltRadar analysis outputs.

The main final output produced by the notebook is the **2026 country-level market assessment dataset**.

For each country, the output includes:

- 2025 import value
- predicted 2026 import value
- predicted import growth rate
- policy direction
- risk level
- opportunity category
- prediction explanation

Generated CSV files are not stored in this repository because they are derived from source datasets that may be subject to licensing, access and redistribution restrictions.

The outputs can be regenerated by running the corresponding export section of the main analysis notebook.
