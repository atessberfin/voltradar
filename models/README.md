# Models

This folder documents the machine-learning model artefacts produced by the VoltRadar workflow.

The final production forecasting model is the **Trade-Only Random Forest (Model 1)**.

The model-export stage of the main analysis notebook produces:

- the trained Trade-Only Random Forest model
- the corresponding production feature configuration required for prediction

The final production model uses the eight trade-related features documented in the main repository README and dissertation.

Exported model artefacts such as `.joblib` and `.pkl` files are not distributed through this repository. They can be regenerated by running the model-export section of:

`notebooks/VoltRadar_Masters_Thesis.ipynb`

This approach keeps the repository lightweight while preserving the complete model-building, evaluation and export workflow in the analysis notebook.
