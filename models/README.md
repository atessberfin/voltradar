# Models

This folder is reserved for exported machine-learning model artefacts used by VoltRadar.

The final production forecasting model is the **Trade-Only Random Forest**.

The notebook exports:

- the trained Random Forest model
- the production feature configuration required by the model

Model artefacts such as `.joblib` and `.pkl` files are not stored in this repository. They can be regenerated by running the model-export section of the main analysis notebook.

This approach keeps the repository lightweight while preserving the full model-building and export workflow.
